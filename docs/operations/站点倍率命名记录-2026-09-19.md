# 线路名称改为站点与倍率（2026-09-19）

名称统一为 `站点名称 · 实际倍率`，例如 `nvtokens · 0.3×`。本次覆盖 43 条探针线路及按 URL、Key 精确匹配的 20 个调度账号。

实际倍率使用令牌绑定分组的适用倍率（含用户专属倍率），除以渠道设置的充值倍率。高峰定价显示折算后的范围；未取得倍率时显示“倍率未知”，不假设为 1 倍。同一站点、同一倍率可以同名，底层 ID 和各自的探针记录、关联关系保持独立，详情仍显示分组与令牌 ID。

已接管调度账号会在倍率或充值倍率变化后自动同步名称；修改只提交名称字段，保留凭据、模型和调度状态。名称更新请求持久记录，超时后回读核对。未接管账号保留用户手动管理方式。上游服务商的原 API 密钥名称仍保留为元数据。
